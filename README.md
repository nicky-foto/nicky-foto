## 👨‍💻 เกี่ยวกับตัวผม

DevOps Engineer ที่มีความเชี่ยวชาญในการออกแบบและพัฒนาโครงสร้างพื้นฐานด้าน IT สมัยใหม่ ปัจจุบันทำงานที่โรงพยาบาลศูนย์การแพทย์มหาวิทยาลัยแม่ฟ้าหลวง โดยมุ่งเน้นการพัฒนาระบบอัตโนมัติและการจัดการโครงสร้างพื้นฐานแบบ Cloud-Native

### 🎯 ความเชี่ยวชาญหลัก
- 🔄 พัฒนาและดูแล CI/CD Pipeline ด้วย Jenkins และ ArgoCD
- 🐳 ออกแบบและจัดการระบบ Container ด้วย Docker และ Kubernetes
- ☁️ บริหารจัดการ Cloud Infrastructure บน GCP, AWS และ Azure
- 🔧 พัฒนาระบบอัตโนมัติด้วย Infrastructure as Code (IaC)
- 📊 ติดตามและวิเคราะห์ประสิทธิภาพระบบด้วย Prometheus และ Grafana

## 💼 ประสบการณ์และความรับผิดชอบ

### 🔹 การพัฒนาระบบอัตโนมัติ
- วางแผนและพัฒนา CI/CD Pipeline เพื่อเพิ่มประสิทธิภาพในการส่งมอบซอฟต์แวร์
- ออกแบบระบบ Infrastructure as Code ด้วย Terraform
- สร้างระบบ Monitoring และ Alerting แบบอัตโนมัติ

### 🔹 การบริหารจัดการ Cloud
- ออกแบบและจัดการ Cloud Architecture บน GCP, AWS และ Azure
- พัฒนาระบบ Multi-cloud และ Hybrid-cloud
- ดูแลความปลอดภัยและประสิทธิภาพของระบบ Cloud

### 🔹 Container Orchestration
- บริหารจัดการ Container ด้วย Docker และ Kubernetes
- พัฒนาระบบ Microservices Architecture
- จัดการ Service Mesh และ Container Security
