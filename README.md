## 🤖 AI & Automation

นำเครื่องมือ AI มาประยุกต์ใช้กับงาน DevSecOps เพื่อเร่งความเร็วในการพัฒนาและยกระดับคุณภาพของระบบ

- 🧠 **Anthropic Claude & Claude Code** — ใช้ผ่าน Claude Code ในการเขียน/รีวิวสคริปต์ automation, สร้าง Pipeline และช่วย troubleshoot ระบบ *(Certified: Claude 101, Claude Code 101 — Anthropic, 2026)*
- ✍️ **Prompt Engineering** — ออกแบบ prompt อย่างเป็นระบบเพื่อให้ได้ผลลัพธ์ที่แม่นยำและทำซ้ำได้
- 💡 **GitHub Copilot** — AI pair programming สำหรับเร่งงานเขียนโค้ดและ IaC
- ⚙️ **AI-Assisted DevOps** — ประยุกต์ AI กับการเขียน config, การวิเคราะห์ log และการสร้างเอกสารอัตโนมัติ
- 🔍 สนใจต่อยอดด้าน **MLOps / LLMOps** สำหรับการ deploy และ monitor AI workloads บน Kubernetes
